## 摘要
高维数据在诸多科学领域中常呈现稀疏结构及时空依赖性。我们针对时空场景开发了一种贝叶斯特征提取框架，该框架采用高斯先验与扩散伽马先验以诱导结构化稀疏性。建模框架通过布雷格曼散度定义广义似然函数，从而兼容多种损失函数与测量模型。后验计算通过马尔可夫链蒙特卡洛（MCMC）方法实现，并引入基于后验样本的两阶段特征提取流程，以稳定跨空间与时间的特征选择。我们通过一项多被试脑电图（EEG）案例研究验证该方法，该研究聚焦慢性酒精暴露与不同脑区活动之间的关系。首先在每个时间点拟合二分类模型，随后在伪发现率控制的筛选及后续聚类的两阶段特征提取流程中识别活跃脑区。分析表明，所提出的先验能够改善稀疏特征的恢复，并在存在时空依赖性的场景下增强可解释性。该框架广泛适用于需要准确特征选择与推断的高维结构化问题。模型实现代码已通过GitHub公开获取。

## Abstract
High-dimensional data with sparse structure and spatio-temporal dependence arise in many scientific domains. We develop a Bayesian feature-extraction framework for spatio-temporal settings that employs Gaussian and Diffused-gamma priors to induce structured sparsity. The modeling framework specifies a general likelihood via Bregman divergence, enabling compatibility with a range of loss functions and measurement models. Posterior computation is carried out via Markov chain Monte Carlo (MCMC), and we introduce a two-stage feature-extraction procedure based on posterior samples to stabilize selection across space and time. We illustrate the method with a multi-subject electroencephalography (EEG) case study examining the relationship between chronic alcohol exposure and activity in different brain regions. We first fit binary classification models at each time point, then use false discovery rate-controlled screening and subsequent clustering in a two-stage feature-extraction pipeline to identify active brain regions. The analysis demonstrates that our proposed priors improve recovery of sparse features and enhance interpretability in the presence of spatio-temporal dependence. The framework is broadly applicable to high-dimensional, structured problems where accurate feature selection and inference are required. The code to implement the model is publicly available via GitHub.

- **研究动机**：高维时空数据（如EEG、fMRI）常呈现“样本量远小于预测变量数”（n ≪ p）的稀疏结构，且存在跨空间和跨时间的相关性。传统统计方法（如普通最小二乘）无法处理此类“高维小样本”问题，而常见的正则化方法（如LASSO）难以量化不确定性，且不能有效利用时空结构。
- **核心挑战**：脑电数据中，每个被试有57个空间位置×256个时间点，共14592个预测变量，但仅有122个被试。需要同时实现变量选择（识别活跃脑区）和分类（预测是否酒精暴露）。
- **整体含义**：提出一种完全贝叶斯框架，通过高斯-扩散伽马（GD）先验诱导结构化稀疏性，结合局部建模（在每个时间点单独建模）降低维度，并设计两阶段特征提取流程（FDR控制筛选+聚类）以稳定地选择活跃脑区，同时进行加权预测。

## 2. 方法论

### 2.1 核心思想
- **局部建模**：在每个时间点 t（共τ个时间点）分别建立二分类逻辑回归模型，以空间位置（电极）为预测变量，被试的酒精暴露状态为响应变量。这样将原始三维数据（n×L×τ）转换为τ个独立的n×L问题，避免了向量化带来的极高维度。
- **Bregman散度似然**：使用Bregman散度作为损失函数，通过其对偶性得到广义似然函数 fψ(y|β) ∝ exp{−BDψ(y, h(Xβ))}，兼容多种响应分布（如伯努利、高斯、泊松）。本文采用伯努利散度，对应逻辑回归。
- **GD先验**：先验 π(β,d) ∝ πG(β|d)πD(d)，其中 πG(β|d) 为高斯分布（均值0，方差1/dj），πD(d) 为扩散伽马分布（形状参数 λ - 1/2，尺度参数 τ₀²/(2(X⁽ʲ⁾)ᵀX⁽ʲ⁾)）。该先验可导出连续可微的ℓ₀范数近似惩罚函数 ˜ℓ₀(β|λ,τ₀)，避免了传统ℓ₀范数的组合优化困难。
- **超参数处理**：传统方法通过网格搜索选择正则化参数λ，本文则给λ赋予弱信息伽马先验（形状0.1，速率0.2），实现完全贝叶斯化，避免网格搜索的计算开销。
- **后验计算**：采用MCMC（具体用rstan中的Hamiltonian Monte Carlo）采样后验分布。对每个时间点独立运行MCMC，得到后验样本。

### 2.2 技术细节
- **第一阶段：FDR控制筛选**  
  基于MCMC后验样本，计算每个位置l在时间t的“后验包含概率” pₗₜ = (1/N) Σ 1(|βₗₜ⁽ˢ⁾| ≤ c)，其中c=10⁻³。pₗₜ可解释为局部FDR。选择阈值ψα，使得平均FRA控制在α（如α=0.05），将pₗₜ < ψα的(l,t)对视为活跃。由此得到稀疏系数矩阵（含精确零）。
- **第二阶段：k-means聚类**  
  对每个位置l，将其在第一阶段得到的估计系数向量β̂ₗ*（长度τ）视为一条时间序列曲线。计算该曲线下的面积（AUC），然后对L个位置的AUC值进行k=2的k-means聚类，将具有较大质心的类确定为活跃位置。
- **加权预测**  
  对每个被试i，在每个时间点t得到预测概率 p̂ᵢₜ = h(xᵢₜᵀβ̂ₜ)。定义权重 wᵢₜ = (p̂ᵢₜ - 0.5)² / Σₜ(p̂ᵢₜ - 0.5)²，最终预测ȳᵢ = 1 若 Σ wᵢₜ p̂ᵢₜ > 0.5，否则0。该加权方法强调了预测概率接近0或1（即信号强）的时间点。

## 3. 实验设计

### 3.1 数据集与场景
- **模拟数据**：模仿EEG结构生成三维数据（n=122，L∈{25,60,75}，τ∈{100,175,250}），随机设定20%的位置为活跃，每个活跃位置含有不同比例的1（活跃时间点）。添加不同信噪比（SNR=1, 1/1.5, 1/2）的噪声。共9种组合，每种重复100次。
- **真实EEG数据**：公开数据集（UCI EEG Database），122名被试（77酒精暴露，45对照），57个有效电极，256个时间点（1秒记录，256Hz采样）。响应为二分类（酒精 vs 对照）。

### 3.2 Benchmark方法与对比
- **对比方法**：LASSO、自适应LASSO（a-LASSO）、弹性网络（E-Net）、MCP、SCAD。使用留一交叉验证（LOOCV）评估。
- **评估指标**：估计精度（rMSE）、特征选择正确率（正确/错误选择的比例）、预测TPR、FPR、预测误差（PE）、AUC。模拟中还报告ROC曲线和AUC。

## 6. 主要结论与发现
- **特征选择**：GD方法在模拟中能以较高TPR和较低FPR识别活跃位置，尤其当时间点τ较多时效果更好。真实EEG数据中，平均每折选出约3.87个活跃电极（占6.79%），其中CP5、P7、PO7在几乎所有折叠中被选出（频率≥121/122），表明这些顶叶区域与酒精暴露关联显著。
- **分类性能**：GD方法在EEG上达到预测误差26.23%（准确率73.77%），TPR=0.7143, FPR=0.2222，AUC=0.7856。与对比方法相比，FPR最低（与a-LASSO并列），AUC仅次于a-LASSO（0.7968）。优于先前基于spike-and-slab的方法（预测误差29.97%）。
- **计算效率**：局部建模可并行化，总运行时间在可接受范围内（约36分钟并行）。
- **可解释性增强**：通过两阶段流程，不仅给出分类，还能明确识别活跃脑区及其时空模式。

## 7. 优点
- **完全贝叶斯框架**：可量化不确定性（后验分布），避免了点估计无法提供标准误的问题。给λ赋予先验，避免了网格搜索的主观性和计算开销。

- **连续可微的ℓ₀近似**：GD惩罚比SELO更平滑，便于梯度优化和HMC采样。
- **两阶段特征提取**：FDR控制提供统计严谨性，聚类避免了固定阈值，更具适应性。

## 8. 不足与局限
- **未显式建模时空相关性**：局部建模假设时间点之间条件独立，第二阶段聚类虽部分利用了时间信息，但未在模型中嵌入时空协方差。作者也承认这是未来方向。
- **第二阶段聚类采用k-means（k=2）**：对于可能有多于两类活跃模式的情况（如不同行为对应的脑区簇），k=2可能过于简化。轮廓系数虽支持2类，但未探讨其他聚类方法或重叠聚类。
- **对比方法可能不公平**：对比的LASSO等方法采用向量化全模型（同时考虑所有时空特征），而GD采用局部建模+两阶段选择。两种策略本质不同，尽管结果可比，但公平性需警惕（向量化模型忽略时空结构，而GD利用了结构）。
- **超参数选择未充分检验**：τ₀=10⁻⁵、c=10⁻³、α₁=0.1, α₂=0.2等选择虽在敏感性中部分验证，但缺少对联合调整的系统性分析。

- **局限应用场景**：方法要求数据为三维数组（n×L×τ），且响应为二分类。扩展到多分类或连续响应需调整Bregman散度，尚未验证。
